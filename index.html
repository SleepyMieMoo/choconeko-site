About

How ChocoNeko is made

ChocoNeko is a small project led by SleepyMie. AI agents write the code, and SleepyMie stays in charge of what actually goes into the game.

  1. SleepyMie leads

    Decides what to build, playtests it and approves the result.

  2. AI agents write code

    AI agents write the code, mostly as pull requests.

  3. Reviewed and tested

    Pull requests are reviewed by another AI agent, and SleepyMie tests changes in Roblox Studio and on the published game.
